# Fiverr Gig: Data-Driven PPT

AI 驱动的演示文稿生成服务 - 基于真实数据生成专业图表 + 创赛 Deck 模板 + 量化分析可视化。

## Gig 文案

### 标题

"Data-Driven PPT Generation | AI Charts | K-Line & Decision Tree Visualization"

### 描述

I create professional, data-driven presentations with AI-powered visualizations.

**What you get:**

- 11 chart types (line/bar/pie/scatter/histogram/area/waterfall/combo/kline/decision_tree)
- A-share K-line charts (red-up-green-down) with MA overlay + volume subplot
- AI decision tree visualization (BFS layout + highlighted paths)
- Dark/light themes with CJK font support
- Competition deck template (11-page standard structure)

**Perfect for:**

- Startup pitch decks
- Competition presentations
- Quantitative analysis reports
- Trading strategy documentation
- AI/ML project showcases

**Tech stack:**

Python + matplotlib + visualization-mcp v0.2.0 + ppt-master

## 发布指南

### 1. 创建 Fiverr 账号

- 访问 https://www.fiverr.com/signup
- 选择 "Become a Seller"
- 完善个人资料（头像 + 简介 + 技能）

### 2. 发布 Gig

- 访问 https://www.fiverr.com/buyers/buyers-sellers/become-a-seller
- 选择 "Create a Gig"
- 填写：
  - Title: 使用上方标题
  - Category: "Presentation" 或 "Data Visualization"
  - Description: 使用上方描述
  - Price: 设置 Basic/Standard/Premium 价格
  - Delivery time: 设置交付时间
  - Requirements: 添加客户需求表单（项目名 / 数据 / 风格偏好）

### 3. 上传作品集

- 将 portfolio/ 下的项目截图上传到 Fiverr
- 每张截图添加说明（项目名 + 功能 + 技术栈）

### 4. 发布后

- 监控订单通知
- 按时交付
- 请求好评
