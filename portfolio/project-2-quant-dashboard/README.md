# Project 2: Quant Dashboard

量化分析仪表盘 - 实时市场数据可视化。

## 项目简介

Quant Dashboard 是一个量化分析仪表盘，提供实时市场数据、技术指标分析、交易信号生成等功能。

## 技术栈

- Python + FastAPI
- Plotly Dash
- visualization-mcp v0.2.0（combo 图 + waterfall 图）
- yfinance / AkShare

## 核心功能

1. **实时市场数据**: 股票 / 基金 / 期货行情
2. **技术指标分析**: MA / MACD / RSI / BOLL
3. **交易信号生成**: 买入 / 卖出信号
4. **风险分析**: 回撤 / 波动率 / Sharpe Ratio
