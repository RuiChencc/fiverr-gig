# Project 3: Competition Deck

创赛 Deck 模板 - 11 页标准骨架 + 叙事三元组。

## 项目简介

Competition Deck 是一个创赛 Deck 模板库，提供 11 页标准骨架 + 叙事三元组 + 时间控制 + 视觉风格 + 参赛话术。

**适用于**: 竞赛 / 黑客松 / 创新赛 / 创业路演。

## 技术栈

- Markdown + ppt-master
- visualization-mcp v0.2.0（图表生成）

## 核心功能

1. **11 页标准骨架**: 封面 / 目录 / 问题 / 方案 / 功能 A / 功能 B / 创新 / 对比 / 实证 / 前景 / 团队
2. **叙事三元组**: 每页 Takeaway（一句话）+ 关键要素
3. **时间控制**: 8 分钟演讲 + Q&A 时间分配
4. **视觉风格**: 暗色主题 + 配色 + 字体（与 visualization-mcp v0.2.0 对齐）
